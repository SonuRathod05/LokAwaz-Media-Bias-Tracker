# ⚖️ LokAwaz: Media Bias Tracker

## 📌 Project Overview
The **Media Bias Tracker** is the second installment of the LokAwaz series. This project moves beyond general sentiment to identify "Political Lean." By analyzing controlled headline groups, it identifies which news sources act as "Fan Clubs" versus "Critics" for specific political entities.

## 🚀 Key Features
* **Entity-Based Mapping:** Specifically tracks bias toward political parties (BJP vs INC).
* **Bias Tug-of-War:** A diverging visualization showing the emotional "pull" of a news source.
* **Accuracy-Bias Correlation:** Investigates if highly biased reporting leads to lower factual accuracy.

## 🛠️ Technology Stack
* **Language:** Python
* **Library:** Pandas, Seaborn, Matplotlib
* **Color Palette:** Custom Entity Mapping (Orange for BJP, Blue for INC)

## 📊 Core Insight
Our analysis revealed that hypothetical sources like *The Global Times* showed a high bias intensity (-0.9) against specific entities, while *Daily Bharat* maintained a more moderate leaning profile.
